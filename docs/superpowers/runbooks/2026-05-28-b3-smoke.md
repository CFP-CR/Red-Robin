## Setup

```powershell
# 0. STOP the daemon BEFORE cleaning — SQLite holds episodic.db open
#    while the daemon runs, and Windows refuses to delete locked files.
redrobin daemon stop -ErrorAction SilentlyContinue
# Fallback if the stop subcommand doesn't exist or hangs:
Get-Process redrobin -ErrorAction SilentlyContinue | Stop-Process -Force
```

```powershell
# 1. Clean manual-smoke state (errors are SURFACED, not swallowed —
#    `Remove-Item -ErrorAction SilentlyContinue` hides the SQLite lock
#    failure on episodic.db, which lets stale state survive the cleanup).
$e = "$env:USERPROFILE\.redrobin\engagements\manual-smoke"
foreach ($f in @("working_memory.json","events.jsonl","episodic.db","dedup_keys.json")) {
    $p = "$e\$f"
    if (Test-Path $p) {
        try { Remove-Item $p -ErrorAction Stop; "deleted $f" }
        catch { "FAILED $f -> $($_.Exception.Message)" }
    } else { "skip $f (does not exist yet)" }
}
Remove-Item "$env:USERPROFILE\.redrobin\working_memory.json" -ErrorAction SilentlyContinue

# Verify: must show ONLY engagement.yaml. If anything else appears
# (episodic.db, working_memory.json, events.jsonl), a process still has
# a handle on it — re-stop the daemon and retry.
Get-ChildItem $e | Select-Object Name
```
